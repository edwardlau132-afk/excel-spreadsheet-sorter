# 📊 Excel Spreadsheet Sorter

A simple, fast, and beautiful web application to sort Excel and CSV files by column headers directly in your browser.

## ✨ Features

- 📤 **Upload Excel Files** - Support for .xlsx, .xls, and .csv formats
- 🔄 **Sort by Any Column** - Click to select which column to sort by
- ⬆️⬇️ **Ascending/Descending** - Choose your sort order
- 🔙 **Reset Data** - Quickly return to original file order
- 📱 **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- ⚡ **Fast Processing** - All sorting happens in your browser (no server needed)
- 🔒 **Private** - Your data never leaves your device

## 📝 How to Use

1. **Upload a File**
   - Click on the file input or drag & drop an Excel/CSV file
   - Click "Upload File" button

2. **Select Sort Column**
   - Choose which column you want to sort by from the dropdown

3. **Choose Sort Order**
   - Select "Ascending (A-Z)" or "Descending (Z-A)"

4. **Sort**
   - Click the green "Sort" button to apply sorting

5. **Reset**
   - Click "Reset" to return to the original file order

## ❓ FAQ

**Q: Is my data secure?**
A: Yes! All processing happens in your browser. No data is sent to any server.

**Q: Can I sort multiple columns?**
A: Currently, the app sorts by one column at a time. You can reset and sort by different columns as needed.

**Q: What's the file size limit?**
A: Your browser's memory is the limit. Most modern browsers can handle files up to 100MB.

**Q: Can I export the sorted data?**
A: You can copy the table data from your browser, or save it as a new file from your spreadsheet application.
